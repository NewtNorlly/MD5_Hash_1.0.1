# MD5 彩虹表破解系统
基于 Python + Flask + SQLite 的 MD5 哈希值查找工具，内置 AI 兜底查询功能。

---

## 一、项目介绍
本项目是一套完整的 MD5 弱密码破解学习系统，核心思路：
先用**彩虹表**做极速查询，查不到再用 **AI 生成弱密码碰撞**，兼顾速度与覆盖范围。
全程通俗易懂、结构清晰，非常适合学习密码学基础、数据库、Web 接口与 AI 调用。

---

## 二、核心知识讲解

### 1. MD5 是什么？
- MD5 是一种哈希算法，能把任何字符串变成 **32 位十六进制串**。
- 相同密码 → 永远得到相同 MD5。
- 理论不可逆，但**简单密码可以被查表反查**。

### 2. 彩虹表是什么？
- 提前把海量常见密码对应的 MD5 算好，存进数据库。
- 本质：**用空间换时间**，查询速度极快（毫秒级）。

### 3. AI 在这里干嘛？
- AI 不是真破解 MD5，而是**生成最可能的弱密码**。
- 逐个计算 MD5 和目标比对，相当于“智能猜密码”。

### 4. 整体流程
1. 用户输入 MD5
2. 先查彩虹表（最快）
3. 表中没有 → AI 生成弱密码尝试
4. 返回结果：成功/失败、密码、耗时

## 三、设计思路

### 1. 架构设计
- 数据层：build_db.py 生成彩虹表数据库
- 服务层：app.py 提供 Web 接口 + 双阶段查询
- 交互层：网页前端 + 命令行工具

### 2. 查询策略（双阶段）
- 阶段 1：SQLite 彩虹表查询（<10ms）
- 阶段 2：AI 兜底碰撞（约 2~3 秒）
- 优点：快的超快，覆盖更广

### 3. 数据库设计
- 单表 rainbow：hash（主键）+ password
- 哈希索引加速查询
- 批量插入 + 去重，保证性能
